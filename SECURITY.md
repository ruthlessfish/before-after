# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Before-After, please report it responsibly by contacting the project maintainers directly. Do not publicly disclose the vulnerability until it has been addressed.

### Contact

- Email: bubbafoley@gmail.com
- GitHub: [https://github.com/ruthlessfish/before-after/issues](https://github.com/ruthlessfish/before-after/issues)

### Response

The maintainers will acknowledge your report within 48 hours and provide updates on the resolution process.
